Character Debug Tool · v1.1.0

Features

  • Data Asset profiles and Gameplay Tag-based metrics
  • Independent metric update intervals (effective minimum 0.1 s)
  • Persistent history of 500 snapshots per save slot
  • TXT/CSV exports and remappable keyboard controls
  • Six colors and overlay scaling from 60% to 160%
  • Editor camera navigation using coordinates

Installation

  1. Copy the CharacterDebugTool folder into YourProject/Plugins/.
  2. Ensure CharacterDebugTool.uplugin is directly inside that folder.
  3. Enable the plugin and Show Plugin Content in the Content Browser.
  4. Open Tools → Character Debug, select DA_DefaultDebugFeatures and place the manager in the level.
  5. Save the level and start Play.

Quick start

  1. Release 0 to toggle the overlay.
  2. Release 9 to capture values while the overlay is open.
  3. F6 cycles colors; −/+ or Num −/Num + changes scale.
  4. F7 restores white and 100% scale.
  5. Select a snapshot in the inspector and export TXT or CSV to Saved/CharacterDebug/Exports.

Extending metrics

Create a child of BP_GetFeatureValue and implement GetFeatureValue_BPI. Register its tag in DT_DebugTags, add its mapping to DT_FeatureLogic, then include that tag in a BP_DA_DebugFeatures profile.

Compatibility & scope

Designed for Unreal Engine 5.8 and local player 0; network multiplayer has not been validated. Dependencies: Enhanced Input, Python Editor Script Plugin and Editor Scripting Utilities. Export and camera navigation are editor-only.

Tick Inspector · v1.1.0 · Unreal Engine 5.8.4

Inspect, adjust, and measure primary ticks

A C++ editor plugin for inspecting PrimaryActorTick and PrimaryComponentTick on loaded objects. Inspect tick capability, enablement, registration, intervals, tick groups, prerequisites, and ownership. Configuration inspection and PIE CPU profiling are separate operations.

Download Tick Inspector v1.1.0 ZIP

Installation

  1. Extract the TickInspector folder to YourProject/Plugins/TickInspector, with TickInspector.uplugin directly inside.
  2. Restart Unreal Editor and enable Tick Inspector in Edit → Plugins if necessary.
  3. Open the dockable tool using the Level Editor toolbar or Tools → Tick Inspector.

Prebuilt binaries target Unreal Engine 5.8.4 on Windows x64. Other engine builds require recompiling the included C++ source. Editor-only; no project content or Python dependency.

Inspection and navigation

  • Choose the Editor world or a running PIE world; the selection determines inspection and edit scope.
  • Search by actor, component, class, tick group, level, or object path; filter by enabled, disabled, can/cannot tick, unregistered, actors, or components; sort by table columns.
  • Automatic incremental scans run roughly every two seconds, with Scan now and Cancel scan controls. Scans are snapshots, not synchronized single-frame recordings.
  • Select owners, focus the editor camera, and optionally highlight up to 128 selected actors' projected bounds in cyan.

Editing tick settings

Select one or multiple rows to enable/disable Tick, set a nonnegative interval, or change the configured starting Tick group. Editor-world changes support Undo/Redo and require saving affected assets or levels; PIE-world changes are temporary. Some objects, including Construction Script-generated components, are read-only for persistent edits. Tick Inspector does not force an object to become tick-capable or register missing tick functions.

PIE performance capture

  1. Stop any active PIE session and ensure no other trace capture is running.
  2. Set the measurement duration (0.1–600 seconds; default 10 seconds).
  3. Click Run PIE & measure, reproduce the scenario, and review the automatically opened results.

Results group attributed CPU samples from each actor's primary tick and its components' primary ticks by actor instance. The report includes total CPU milliseconds, milliseconds per captured PIE frame, maximum individual execution, execution count, and share of measured Tick time. Actors without attributable samples are not necessarily zero-cost.

Captured synchronous CPU scopes do not represent total actor cost, GPU time, detached asynchronous work, or a direct FPS improvement prediction. Profiling temporarily changes instrumentation and disables tick batching; confirm optimizations using Unreal Insights in a packaged Development build.

Exports and scope

Export selected or filtered inspection rows to CSV. Trace files are retained under Saved/TickInspector/Captures/*.utrace for Unreal Insights. World Partition and streaming inspection covers loaded objects only. Secondary/custom tick functions, timers, subsystem tickers, external-process games, and remote clients are outside the current scope.
